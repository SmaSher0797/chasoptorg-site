# ЧасОптТорг — набросок сайта

Статический многостраничный макет (HTML/CSS/JS, без сборки и зависимостей).

## Как открыть в WebStorm

1. Распакуйте архив и откройте папку `chasoptorg-site` как проект в WebStorm.
2. Кликните правой кнопкой по `index.html` → **Open in Browser** (или запустите встроенный сервер WebStorm — значок браузера в правом верхнем углу редактора). Открывать файл напрямую двойным кликом (`file://`) тоже можно — сайт не требует сервера, но некоторые браузеры могут ограничивать локальные запросы, поэтому лучше через Open in Browser / Live Preview.

## Структура файлов

- `index.html` — главная
- `catalog.html` — каталог часов
- `product.html` — карточка товара
- `cart.html` — корзина
- `account.html` — личный кабинет (вход/регистрация + пример кабинета)
- `about.html` — о компании и контакты
- `style.css` — общие стили (переменные цвета в самом начале файла — `:root`)
- `script.js` — интерактивность (вкладки, степпер количества, мобильное меню)

Все страницы связаны между собой обычными ссылками `<a href="...">`, так что переходы по сайту работают сразу.
